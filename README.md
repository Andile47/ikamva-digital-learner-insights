# Ikamva Digital – Learner Insights & Analytics Dashboard

## Project Overview

This project focuses on developing an interactive Business Intelligence dashboard prototype for Ikamva Digital using Microsoft Power BI.

The objective is to explore learner demographics, geographical distribution, educational backgrounds and learning pathway preferences through data analysis and visualisation.

The project uses synthetic learner data generated for demonstration purposes because access to the organisation's actual learner database has not been provided.

## Business Objective

Develop a dashboard prototype that demonstrates how data analytics can support organisational decision-making by helping stakeholders understand:

- Learner demographics and distribution.
- Geographic representation across South African provinces.
- Educational backgrounds and institution types.
- Popular digital learning pathways.
- Registration trends over time.

Additional learner engagement and course performance analysis may be introduced if suitable activity data becomes available.

## Dataset Description

A synthetic dataset containing 1,000 fictional learner records was generated.

The initial dataset includes:

- Learner ID
- Registration Date
- Province
- Age Band
- Education Level
- Institution Type
- Learning Pathway

The workbook also includes a data dictionary, pathway reference sheet and dataset documentation.

**Important:** The dataset is entirely fictional. The fields and category options are provisional and have not yet been verified against Ikamva Digital's official learner profile form.

## Project Limitations

- No actual Ikamva Digital learner records are being used.
- The synthetic dataset does not represent the organisation's actual learner population.
- Profile fields and dropdown options are provisional.
- Course engagement and completion cannot be established from registration profile data alone.
